# Problem Statement: Personal Finance & Expense Analytics Engine (FinTrack)

## Problem Statement
Managing personal daily finances manually often leads to overspending, poor budget allocation, and a lack of foresight regarding future savings growth. Individuals require a lightweight, transparent computational tool to track expenditures, evaluate safety thresholds against income, and project compound interest earnings using fundamental mathematical algorithms.

## Scope of the Project
FinTrack is a modular Python CLI application built using core problem-solving concepts:
- Computes aggregate expenditures, average daily spending, and identifies min/max spending entries.
- Evaluates monthly budget thresholds and issues alert triggers when exceeding safety limits (80%+ capacity).
- Simulates compound savings growth using power and iteration algorithms over specified time horizons.
- Provides a menu-driven terminal interface with input validation and error handling.

## Target Users
- University students managing monthly stipends and hostel allowances.
- Individuals seeking dependency-free, transparent financial analysis algorithms.

## High-Level Features
1. **Budget Management Module:** Defines monthly limits and evaluates budget health indicators.
2. **Expense Analytics Engine:** Processes expense sequences to calculate total, average, minimum, and maximum amounts.
3. **Savings & Interest Forecaster:** Computes compound interest accumulation across customizable periods.
4. **Interactive CLI Workflow:** Continuous menu loop with input validation.
